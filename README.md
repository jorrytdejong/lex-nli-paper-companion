# LEX-NLI paper companion on GitHub Pages

This repository publishes the static mobile-first companion for the EMNLP 2026 paper.

## Publish

In GitHub, open **Settings → Pages** and set **Deploy from a branch**, branch `main`, folder `/docs`. The expected project-site URL is `https://jorrytdejong.github.io/lex-nli-paper-companion/`.

The pages in `docs/` use relative paths so paper, CSS, favicon, and the evidence page load correctly beneath the GitHub project URL. The original ChatGPT Sites version remains available separately.
